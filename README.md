# C346 Mobile App Development

React Native (Expo) work for C346, RP.

- L3: Week 3 Lesson 05, exercises 1A to 1G
- W3-Quiz: Week 3 Lesson 06 quiz
- L07-Ex1 to L07-Ex4: Week 4 Lesson 07 exercises
- L08-Ex5-Quiz: Week 4 Lesson 08 restyled quiz app
- L08-Ex5-Boats: Week 4 Lesson 08 restyled boats (GetABoat) app

Each folder is its own app. Run `npm install` then `npx expo start` inside it.

New weeks get added as new folders in this repo.
